# MathLab 관리자 페이지 디자인 보고서

## 1. 전체적인 디자인 시스템 및 시각적 계층 구조

*   **레이아웃:** 왼쪽 사이드바와 오른쪽 메인 콘텐츠 영역으로 나뉩니다. 관리 효율성을 위해 '마스터-디테일(2개 패널)' 구조를 핵심 관리 페이지(학생, 개념, 문제, 시험 관리 등)에 일관되게 적용하고 있습니다.
*   **컬러 팔레트:**
    *   **Primary:** 밝고 선명한 블루(#3B82F6)를 사용하여 주요 액션 버튼, 활성 상태, 브랜드 아이덴티티를 강조합니다.
    *   **Neutral:** Slate 계열의 그레이 톤을 배경, 텍스트, 경계선에 사용하여 깔끔하고 현대적인 느낌을 줍니다.
    *   **Accent:** 카드 배경에 파스텔 톤(퍼플, 그린, 옐로우 등)을 사용하여 시각적 단조로움을 피하고 정보를 구분합니다.
*   **타이포그래피:** 현대적인 Sans-serif 서체(Pretendard 등)를 사용하며, 굵기와 크기를 활용해 제목과 메타데이터 간의 위계를 명확히 구분합니다.

## 2. 주요 UI 구성 요소

*   **사이드바:** 기능별(메인 메뉴, 시스템, 어드민)로 그룹화되어 있으며, 현재 위치를 블루 컬러와 볼드체로 표시하여 직관적인 네비게이션을 제공합니다.
*   **카드(Cards):** 흰색 배경에 아주 얇은 테두리와 부드러운 라운딩 처리를 하여 가독성이 높고 정리된 느낌을 줍니다. 대시보드와 대시보드 요약 지표에 주로 사용됩니다.
*   **버튼 스타일:**
    *   **주요 버튼:** 꽉 찬 블루 배경에 흰색 텍스트로 시인성이 높습니다.
    *   **보조 버튼:** 테두리만 있는 아웃라인 스타일(오렌지, 그레이)을 사용하여 우선순위를 조절합니다.
*   **폼(Forms) 및 입력 필드:** 깔끔한 테두리와 포커스 시 블루 링 효과를 주어 안정적인 입력 경험을 제공합니다. 학습지 생성기와 같은 복잡한 과정은 '스테퍼(Step 1-3)'를 통해 시각적으로 단계화했습니다.
*   **데이터 시각화:** 월간 학습 추이 등에 차트를 활용하고, 학생 관리 등에서는 리스트와 상세 정보 패널을 동시에 보여주어 편집 효율을 높였습니다.

## 3. 사용자 경험 (UX) 특징

*   **일관성:** 모든 관리 페이지가 동일한 패널 구조와 버튼 위치를 유지하여 사용자가 새로운 메뉴에 쉽게 적응할 수 있습니다.
*   **검색 및 필터:** 상단 또는 왼쪽 패널에 학년, 레벨, 유형 등 상세 필터와 검색창을 배치하여 방대한 교육 데이터를 빠르게 찾을 수 있도록 설계되었습니다.
*   **상태 표시:** '활성', '통과', '관리 필요' 등의 상태를 컬러 배지로 표시하여 즉각적인 상황 판단이 가능합니다.
*   **빈 화면 처리:** 데이터가 없을 때 일러스트와 함께 친절한 가이드 문구를 제공하여 사용자 이탈을 방지합니다.

## 4. 탐색한 주요 페이지 요약

1.  **대시보드:** KPI 요약 카드, 월간 학습 추이 그래프, 집중 관리 필요 학생 리스트 제공.
2.  **학생/개념/문제/시험 관리:** 좌측 리스트 선별 후 우측 상세 조회/편집의 일관된 2패널 구조.
3.  **연산 생성기:** 간단한 조건 설정만으로 대량의 연산 문제를 생성하는 폼 기반 도구.
4.  **학습지 만들기:** 학년 선택부터 상세 설정까지 이어지는 3단계 위저드 형식.
5.  **학습 분석:** 알록달록한 통계 카드와 PDF 다운로드/인쇄 기능을 갖춘 리포트 뷰.

## 5. 총평

전반적으로 **'신뢰감 있고 전문적인 교육용 SaaS 플랫폼'**의 느낌을 주며, 복잡한 교육 데이터를 직관적이고 효율적으로 관리할 수 있도록 설계된 인터페이스를 갖추고 있습니다.
