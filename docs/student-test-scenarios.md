## 시나리오 1: 로그인 + 대시보드

### 1-1. 로그인
- [ ] `/login` 접속
- [ ] `student01` / `1234` 입력 후 로그인
- [ ] `/dashboard`로 리다이렉트 되는지 확인
- [ ] 사이드바에 "이수학" 이름 + "학생" 역할 표시

### 1-2. 대시보드 — 상단 영역
- [ ] 환영 메시지에 학생 이름 표시
- [ ] XP 배지: 총 XP 포인트 표시
- [ ] 연속 학습(스트릭) 배지 표시 (0이면 미표시)
- [ ] 숙제 배너: 오늘 숙제가 있으면 배너 표시
  - [ ] 연산 숙제 배너 클릭 → `/practice/arithmetic/homework` 이동
  - [ ] 개념 숙제 배너 클릭 → `/concepts/[id]` 이동
  - [ ] 문제 숙제 배너 클릭 → `/practice/question-homework` 이동

### 1-3. 대시보드 — 통계 카드 (4개)
- [ ] **현재 레벨**: 레벨 숫자 + 다음 레벨까지 남은 XP 표시
- [ ] **나의 포인트**: 총 XP 숫자
- [ ] **완료 개념**: 완료/전체 + 진행률 %
- [ ] **주간 활동**: 최근 7일 활동 건수

### 1-4. 대시보드 — 진행 중인 학습
- [ ] 학습 과정이 배정되어 있으면 개념 목록 표시
- [ ] "시작하기" 또는 "이어서 하기" 버튼 클릭 → 해당 개념 페이지 이동
- [ ] 배정 과정이 없으면 최근 학습한 개념 또는 "학습 시작" 버튼 표시

### 1-5. 대시보드 — 게이미피케이션
- [ ] **일일 미션** 카드 표시 (미션 목록 + 완료 여부)
- [ ] **오늘의 문제** 카드 표시 (문제 내용, 보기, 제출 버튼)

### 1-6. 대시보드 — 하단 영역
- [ ] **최근 오답**: 최대 5개, "복습하기" 링크 → `/practice/revenge`
- [ ] **주간 학습량 차트**: 최근 7일 막대 그래프 표시
- [ ] **실시간 랭킹**: 상위 5명, 현재 학생 강조, "전체 순위 보기" → `/ranking`

## 시나리오 2: 단원 목록 + 개념 학습

### 2-1. 단원 목록
- [ ] 사이드바 "단원 목록" 클릭 → `/subjects`
- [ ] 배정된 학습 과정이 표시되는지 확인
- [ ] 과목별 개념 목록 표시 (분수, 도형 등)
- [ ] 개념 클릭 → `/concepts/[id]` 이동

### 2-2. 개념 학습 — 1단계 (개념 읽기)
- [ ] 개념 페이지 진입
- [ ] 마크다운 콘텐츠 렌더링 확인 (제목, 본문, 수식)
- [ ] KaTeX 수식이 정상 렌더링 되는지 확인
- [ ] "학습 완료" 버튼 클릭 → READING 단계 완료
- [ ] 완료 토스트 알림 표시
- [ ] XP 획득 알림 표시 (5 XP)

### 2-3. 개념 학습 — 2단계 (빈칸 쉬움)
- [ ] BLANK_EASY 단계 자동 전환
- [ ] 빈칸 문제 표시 (핵심 용어만 빈칸)
- [ ] 초성 힌트 표시 확인
- [ ] 정답 입력 → 채점 결과 표시
- [ ] 모두 정답 → 10 XP 획득 + 다음 단계 전환

### 2-4. 개념 학습 — 3단계 (빈칸 어려움)
- [ ] BLANK_HARD 단계
- [ ] 더 많은 빈칸 표시 (easy + hard)
- [ ] 정답 입력 → 채점 → 15 XP

### 2-5. 개념 학습 — 4단계 (빈칸 전체)
- [ ] BLANK_FULL 단계
- [ ] 거의 모든 키워드가 빈칸
- [ ] 정답 입력 → 채점 → 20 XP

### 2-6. 개념 학습 — 5단계 (백지 쓰기)
- [ ] BLANK_PAGE 단계
- [ ] 텍스트 영역에 자유롭게 내용 작성
- [ ] "제출" 클릭 → 점수(%) 표시
- [ ] 70% 이상이면 통과 → 30 XP

### 2-7. 이전/다음 개념 네비게이션
- [ ] 개념 페이지 하단에 이전/다음 버튼 표시
- [ ] 클릭 시 같은 학년 내 다음 개념으로 이동

## 시나리오 4: 나의 시험

### 4-1. 시험 목록
- [ ] 사이드바 "나의 시험" → `/my-tests`
- [ ] 배정된 시험 목록 표시
- [ ] 상태별 구분: ASSIGNED(미응시), IN_PROGRESS(진행중), COMPLETED(완료)
- [ ] 마감일 표시

### 4-2. 시험 응시

- [ ] 문제 표시 (마크다운 + KaTeX 수식)
- [ ] 객관식: 보기 5개 클릭 선택
- [ ] 주관식: 텍스트 입력
- [ ] 이전/다음 문제 네비게이션
- [ ] 타이머 표시 (시간제한 있는 경우)
- [ ] "제출" 클릭 → 확인 다이얼로그 표시
- [ ] 제출 후 → `/my-tests/[id]/result` 리다이렉트

### 4-3. 시험 결과
- [ ] `/my-tests/[id]/result` 접속
