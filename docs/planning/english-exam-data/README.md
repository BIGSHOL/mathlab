## 확정한 명명 규칙 (topic 항목 문자열)

교육과정은 문법 항목을 **학년별로 고시하지 않는다**(별표4는 학교급 권장). 내신 분석 topic은 교과서·참고서가 공유하는 **한글 학교문법명**을 쓴다.

1. **기본**: 짧은 한글명. 예: `be동사`, `to부정사`, `관계대명사`, `현재완료`.
2. **괄호는 닫힌 형태 집합에만**. 예: `be동사 (am, is, are)`, `There is/are`.  
   주제 나열(`가족, 학교, 음식…`)·문장 수(`7-10문장`)·수능 유형 묶음은 topic 잎에 넣지 않는다. 매칭 키가 시험마다 흔들린다.
3. **어휘 잎은 교육과정 상한으로**. `기초 어휘 500단어`는 2022 중학 상한(1,500단어 이내, 중1~3 합)과 불일치하므로 폐기. 학년 잎은 `교육과정 기본 어휘(해당 학교급)` + `문맥상 어휘`.
4. **독해 잎은 성취기준 기능명**. `짧은 대화문 (3-5문장)` 대신 `세부 정보 파악`, `주제·요지`, `함축적 의미`. 장르는 부가 키워드.

상세 표는 [topics-by-grade.md](./topics-by-grade.md).
