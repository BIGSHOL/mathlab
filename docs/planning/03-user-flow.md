# User Flow (사용자 흐름도) — MathLab

> Mermaid 플로우차트로 핵심 기능의 주요 여정을 표현합니다.

---

## MVP 캡슐

| # | 항목 | 내용 |
|---|------|------|
| 1 | 목표 | 초중등 학생들이 강의 없이 수학 개념을 자기주도적으로 이해할 수 있는 학원용 학습 프로그램 |
| 2 | 페르소나 | 초중등학생 (학원 소속, 수업 전후 자기주도 학습) |
| 3 | 핵심 기능 | FEAT-1: 단계적 개념 학습 (읽기→빈칸→백지) |
| 4 | 성공 지표 (노스스타) | 백지 쓰기 단계까지 도달한 학생 비율 |
| 5 | 입력 지표 | 주간 로그인 횟수, 단계별 완료율 |
| 6 | 비기능 요구 | 모든 기기 반응형 웹 (PC/태블릿/스마트폰) |
| 7 | Out-of-scope | 외부 API 연동, 학부모 카카오톡 알림, 학원 내 상점 |
| 8 | Top 리스크 | 학생들이 초기 흥미를 잃고 사용을 중단할 수 있음 |
| 9 | 완화/실험 | 포인트/랭킹/레벨업 게이미피케이션으로 지속 동기 부여 |
| 10 | 다음 단계 | FEAT-1 단계적 개념 학습 프로토타입 개발 |

## 1. 전체 사용자 여정 (Overview)

```mermaid
graph TD
    A[앱 진입] --> B{로그인 상태?}
    B -->|No| C[FEAT-0: 로그인]
    B -->|Yes| D[메인 화면 - 학습 대시보드]
    C --> D

    D --> E{역할?}
    E -->|학생| F[FEAT-1: 단계적 개념 학습]
    E -->|선생님| G[관리 대시보드]

    F --> H[학습 완료 → 포인트 획득]
    H --> I[레벨업 / 랭킹 확인]
    I --> D

    G --> J[학생 계정 관리]
    G --> K[학습 진도 확인]
```

## 2. FEAT-0: 로그인 플로우

```mermaid
graph TD
    A[시작 화면] --> B[로그인 폼]
    B --> C[아이디/비밀번호 입력]
    C --> D{인증 성공?}

    D -->|Yes| E{역할 확인}
    E -->|학생| F[학생 메인 화면]
    E -->|선생님| G[관리 대시보드]

    D -->|No| H[에러 표시 - 아이디/비밀번호 확인]
    H --> B

    %% 비밀번호 분실
    B --> I[비밀번호 분실]
    I --> J[선생님에게 문의 안내]
```

## 3. FEAT-0: 학생 계정 관리 (선생님) 플로우

```mermaid
graph TD
    A[관리 대시보드] --> B[학생 관리 메뉴]
    B --> C{작업 선택}

    C -->|계정 생성| D[학생 정보 입력]
    D --> E[이름 / 학년 / 아이디 / 초기 비밀번호]
    E --> F{입력 검증}
    F -->|유효| G[계정 생성 완료]
    F -->|오류| H[에러 표시]
    H --> D

    C -->|계정 수정| I[학생 선택]
    I --> J[정보 수정]
    J --> K[저장]

    C -->|비밀번호 초기화| L[학생 선택]
    L --> M[새 비밀번호 설정]
    M --> N[초기화 완료]
```

## 4. FEAT-1: 단계적 개념 학습 플로우 (MVP 핵심)

```mermaid
graph TD
    A[학생 메인 화면] --> B[단원 선택]
    B --> C[개념 선택]
    C --> D{학습 진도 확인}

    %% Stage 1: 읽기
    D -->|미시작/읽기 단계| E[📖 Stage 1: 개념 읽기]
    E --> F[시각적 설명 - 그림/애니메이션과 함께]
    F --> G[읽기 완료 버튼]
    G --> H[+5 XP 획득! 🎉]

    %% Stage 2: 빈칸 쉬움
    H --> I[✏️ Stage 2: 빈칸 채우기 - 쉬움]
    D -->|빈칸 쉬움 단계| I
    I --> J[핵심 키워드 일부 빈칸]
    J --> K{정답?}
    K -->|Yes| L[+10 XP 획득! 🎉]
    K -->|No| M[오답 피드백 - 힌트 제공]
    M --> J

    %% Stage 3: 빈칸 어려움
    L --> N[✏️ Stage 3: 빈칸 채우기 - 어려움]
    D -->|빈칸 어려움 단계| N
    N --> O[대부분 빈칸으로 표시]
    O --> P{정답?}
    P -->|Yes| Q[+15 XP 획득! 🎉]
    P -->|No| R[오답 피드백 - 관련 부분 다시 읽기 유도]
    R --> O

    %% Stage 4: 백지 쓰기
    Q --> S[📝 Stage 4: 백지 쓰기]
    D -->|백지 쓰기 단계| S
    S --> T[완전히 빈 화면에서 개념 작성]
    T --> U{채점}
    U -->|통과| V[🏆 스테이지 클리어! +30 XP!]
    U -->|미달| W[부족한 부분 표시 → Stage 2로 복귀 가능]

    %% 완료
    V --> X[레벨업 체크]
    X --> Y{레벨업?}
    Y -->|Yes| Z[🎊 레벨업 축하 애니메이션!]
    Y -->|No| AA[다음 개념 추천]
    Z --> AA
    AA --> A
```

## 5. 게이미피케이션 플로우 (포인트/레벨/랭킹)

```mermaid
graph TD
    A[학습 활동 완료] --> B[포인트(XP) 지급]
    B --> C[누적 XP 업데이트]
    C --> D{레벨업 조건 충족?}

    D -->|Yes| E[레벨업! 🎊]
    E --> F[레벨업 애니메이션 + 보상]
    D -->|No| G[현재 진행 상황 표시]

    F --> H[랭킹 업데이트]
    G --> H

    H --> I[랭킹 보드 반영]
    I --> J{순위 변동?}
    J -->|상승| K[순위 상승 알림! ⬆️]
    J -->|유지/하락| L[다음 순위까지 남은 XP 표시]

    K --> M[메인 화면으로]
    L --> M
```

## 6. 리텐션 루프 (습관 형성)

```mermaid
graph TD
    A[개념 학습 완료] --> B[즉각 보상 - XP + 레벨]
    B --> C[진행 상황 저장]
    C --> D[다음 개념 추천]

    %% 연속 학습 보너스
    D --> E{연속 학습?}
    E -->|Yes| F[연속 보너스 XP! 🔥]
    F --> G[다음 개념 시작]
    E -->|No| H[오늘 학습 종료 요약]

    %% 재방문 루프
    I[다음 로그인] --> J{어제 학습 했나?}
    J -->|Yes| K[연속 학습 스트릭 유지! 🔥]
    J -->|No| L[다시 시작하자! 화이팅!]
    K --> G
    L --> G

    %% 랭킹 경쟁 루프
    M[랭킹 확인] --> N{순위 낮음?}
    N -->|Yes| O[동기 부여 - 조금만 더 하면 순위 UP!]
    O --> G
    N -->|No| P[유지/방어 동기]
    P --> G
```

## 7. 에러 처리 플로우

```mermaid
graph TD
    A[에러 발생] --> B{에러 유형?}

    B -->|네트워크| C[인터넷 연결을 확인해주세요!]
    B -->|입력 오류| D[빈칸별 에러 표시]
    B -->|세션 만료| E[다시 로그인해주세요]
    B -->|서버 오류| F[잠시 후 다시 시도해주세요]

    C --> G{재시도?}
    G -->|Yes| H[재시도 실행]
    G -->|No| I[오프라인 알림]

    D --> J[학생이 수정]
    J --> K[재제출]

    E --> L[로그인 화면]

    F --> M[자동 재시도 (3회)]
    M --> N{성공?}
    N -->|Yes| O[정상 진행]
    N -->|No| P[선생님에게 알려주세요!]
```
