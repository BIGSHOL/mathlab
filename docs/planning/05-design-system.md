# Design System (기초 디자인 시스템) — MathLab

> 초중등 학생들이 재미있게 사용할 수 있는 게임형 학습 디자인 시스템입니다.

---

## MVP 캡슐

| # | 항목 | 내용 |
|---|------|------|
| 1 | 목표 | 초중등 학생들이 강의 없이 수학 개념을 자기주도적으로 이해할 수 있는 학원용 학습 프로그램 |
| 2 | 페르소나 | 초중등학생 (학원 소속, 수업 전후 자기주도 학습) |
| 3 | 핵심 기능 | FEAT-1: 단계적 개념 학습 (읽기→빈칸→백지) |
| 4 | 성공 지표 (노스스타) | 백지 쓰기 단계까지 도달한 학생 비율 |
| 5 | 입력 지표 | 주간 로그인 횟수, 단계별 완료율 |
| 6 | 비기능 요구 | 모든 기기 반응형 웹 (PC/태블릿/스마트폰) |
| 7 | Out-of-scope | 외부 API 연동, 학부모 카카오톡 알림, 학원 내 상점 |
| 8 | Top 리스크 | 학생들이 초기 흥미를 잃고 사용을 중단할 수 있음 |
| 9 | 완화/실험 | 포인트/랭킹/레벨업 게이미피케이션으로 지속 동기 부여 |
| 10 | 다음 단계 | FEAT-1 단계적 개념 학습 프로토타입 개발 |

## 1. 디자인 철학

### 1.1 핵심 가치

| 가치 | 설명 | 구현 방법 |
|------|------|----------|
| 재미 (Fun) | 게임하듯 학습하는 즐거움 | 밝은 컬러, 보상 애니메이션, 레벨업 효과 |
| 명확함 (Clarity) | 초등학생도 헷갈리지 않게 | 큰 글씨, 직관적 아이콘, 심플한 레이아웃 |
| 성취감 (Achievement) | 매 단계마다 성장을 느끼게 | 프로그레스 바, XP 카운터, 랭킹 보드 |
| 친근함 (Friendly) | 부담 없이 시작할 수 있게 | 둥근 모서리, 따뜻한 컬러톤, 게임 스타일 톤 |

### 1.2 참고 서비스 (무드보드)

| 서비스 | 참고할 점 | 참고하지 않을 점 |
|--------|----------|-----------------|
| 듀오링고 | 레벨/XP 시스템, 밝고 활기찬 컬러, 즉각적 피드백 | 캐릭터 과의존, 알림 과다 |
| 토도수학 | 깔끔한 학습 레이아웃, 단계적 난이도 표현 | 너무 어린 느낌의 일러스트 |
| 마인크래프트 에듀 | 탐험/성취감 중심 UX, 모험적 분위기 | 복잡한 3D 인터페이스 |

### 3.2 타입 스케일

| 이름 | 크기 | 굵기 | 용도 |
|------|------|------|------|
| Display | 40px | ExtraBold (800) | 레벨업! 스테이지 클리어! |
| H1 | 28px | Bold (700) | 페이지 제목, 단원명 |
| H2 | 22px | SemiBold (600) | 섹션 제목, 개념명 |
| H3 | 18px | SemiBold (600) | 서브섹션 |
| Body Large | 16px | Regular (400) | 개념 설명 본문 |
| Body | 15px | Regular (400) | 기본 본문 (초등학생 가독성 고려 14→15px) |

- 줄간격 1.8 (일반 1.5보다 넓게)
- 단어 간격 약간 넓게 (word-spacing: 0.5px)

## 5. 기본 컴포넌트

### 5.1 버튼 (Button)

| 상태 | Primary (퍼플) | Secondary (오렌지) | Ghost |
|------|----------------|-------------------|-------|
| 기본 | 퍼플 채움 + 흰 텍스트 | 오렌지 테두리 + 오렌지 텍스트 | 텍스트만 |
| 호버 | 약간 밝아짐 + 살짝 확대 (scale 1.02) | 오렌지 채움 + 흰 텍스트 | 밑줄 |
| 포커스 | 퍼플 포커스 링 | 오렌지 포커스 링 | 포커스 링 |
| 비활성 | 50% 투명도 | 50% 투명도 | 50% 투명도 |
| 로딩 | 스피너 표시 | 스피너 표시 | 스피너 표시 |

**크기 (학생용은 Large 기본):**
- Large: 높이 52px, 패딩 24px, 폰트 16px — 학생 주요 버튼
- Medium: 높이 44px, 패딩 16px, 폰트 15px — 일반 버튼
- Small: 높이 36px, 패딩 12px, 폰트 14px — 관리자 UI

### 5.2 빈칸 입력 필드 (Blank Input) — FEAT-1 전용

| 상태 | 스타일 |
|------|--------|
| 기본 (빈) | 점선 테두리, 연한 퍼플 배경, 밑줄 강조 |
| 포커스 | 실선 퍼플 테두리 + 포커스 링 + 살짝 확대 |
| 정답 | 에메랄드 테두리 + 체크 아이콘 + 바운스 애니메이션 |
| 오답 | 코랄 레드 테두리 + X 아이콘 + 셰이크 애니메이션 |
| 힌트 | 앰버 테두리 + 전구 아이콘 + 힌트 텍스트 툴팁 |

### 5.3 카드 (Card)

- 배경: Surface (스노우 화이트)
- 테두리: 1px solid `#E2E8F0`
- 모서리: 12px 라운드 (둥글게)
- 그림자: 0 2px 8px rgba(0,0,0,0.08)
- 내부 여백: lg (24px)
- 호버: 살짝 들어올림 (translateY -2px) + 그림자 강화

### 5.4 프로그레스 바 (Progress Bar)

- 배경: `#E2E8F0`
- 채움: 스테이지 컬러 (그라데이션)
- 높이: 12px (두껍게, 진행 상황 잘 보이게)
- 모서리: 6px 라운드
- 애니메이션: 채움 부분 부드럽게 확장 (0.5s ease)
- XP 텍스트: 바 오른쪽에 "+10 XP" 작게 표시

### 5.5 XP 뱃지 (XP Badge)

- 배경: XP Gold 그라데이션 (`#EAB308` → `#F59E0B`)
- 텍스트: 흰색, Bold
- 모서리: 전체 라운드 (pill shape)
- 사이즈: 높이 28px, 패딩 12px
- 애니메이션: 획득 시 바운스 + 반짝임 효과

### 5.6 랭킹 카드 (Ranking Card)

- 1등: 골드 테두리 + 왕관 아이콘 + 골드 배경
- 2등: 실버 테두리 + 메달 아이콘 + 실버 배경
- 3등: 브론즈 테두리 + 메달 아이콘 + 브론즈 배경
- 4등~: 기본 카드 스타일
- 내 순위: Primary 컬러 테두리 + "나" 뱃지 강조

## 6. 게임 피드백 UI

### 6.1 레벨업 모달

```
┌─────────────────────────────┐
│                             │
│     🎊 레벨업! 🎊           │
│                             │
│     Level 4 → Level 5       │
│                             │
│     ✨ 축하해! 대단해! ✨    │
│                             │
│     [다음 도전 →]            │
│                             │
└─────────────────────────────┘
```
- 컨페티(종이 조각) 애니메이션
- 숫자 카운트업 애니메이션 (4 → 5)
- 1.5초 자동 닫힘 또는 터치로 닫기

### 6.2 포인트 획득 토스트

```
┌──────────────────────┐
│  ⭐ +10 XP 획득!     │
│  빈칸 채우기 완료!    │
└──────────────────────┘
```
- 화면 상단에서 슬라이드 다운
- 2초 후 자동 사라짐
- 골드 그라데이션 배경

### 6.3 스테이지 클리어

```
┌─────────────────────────────┐
│                             │
│    🏆 스테이지 클리어!       │

│    ┌─────────────────────┐  │
│    │ 🔥 연속 5일 학습!   │  │
│    │ 보너스 +5 XP        │  │
│    └─────────────────────┘  │
│                             │
│    [다음 개념 →] [랭킹 확인] │
│                             │
└─────────────────────────────┘
```

## 7. 접근성 체크리스트

### 7.1 필수 (MVP)

- [ ] **색상 대비**: 텍스트와 배경의 대비율 4.5:1 이상
- [ ] **포커스 링**: 키보드 탐색 시 포커스 표시 명확
- [ ] **클릭 영역**: 버튼/링크 최소 48x48px (학생 터치 고려, 44보다 크게)
- [ ] **에러 표시**: 색상만으로 구분하지 않음 (아이콘+텍스트 병행, 정답=체크, 오답=X)
- [ ] **폰트 크기**: 본문 최소 15px (초등학생 가독성)

### 7.2 권장 (v2)

- [ ] 키보드 전체 탐색 가능
- [ ] 스크린 리더 호환 (ARIA 라벨)
- [ ] 애니메이션 줄이기 옵션 (prefers-reduced-motion)
- [ ] 고대비 모드

## 9. 반응형 브레이크포인트

| 이름 | 최소 너비 | 대상 기기 |
|------|----------|----------|
| mobile | 0px | 스마트폰 (세로) |
| tablet | 768px | 태블릿, 스마트폰 (가로) |
| desktop | 1024px | 노트북, 학원 PC |
| wide | 1280px | 큰 모니터 |

**학습 화면 레이아웃:**
- mobile: 싱글 컬럼, 하단 네비게이션
- tablet: 사이드바 접힘, 넓은 콘텐츠 영역
- desktop: 사이드바 + 콘텐츠 + 프로그레스 패널
